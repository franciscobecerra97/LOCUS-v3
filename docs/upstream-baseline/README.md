LOCUS repository at commit
`771fccd14d918b697bfb48fd24a0202c52c7f7ac`.

for this improvement project. The same baseline documents are also present at

made. Some snapshot files contain:

- manuscript or Cycle 1 language;

directory and record the semantic change.

The active authority is the root `AGENTS.md`, `PLAN.md`, charter, protocol
invariants, decision register, evidence policy, active technical documents, and
