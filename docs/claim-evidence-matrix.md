# LOCUS Claim-Evidence Matrix

Status date: 2026-08-17. This document gates manuscript claims for the ASIACCS 2027 Cycle 1 submission.

## Evidence-State Rules

- `Supported`: the claim has evidence matching its stated scope and can be reproduced.
- `Partial`: some relevant design, implementation, proof, test, or citation exists, but the complete paper-facing claim is not yet supported.
- `Planned`: the claim is an intended result with a defined evidence path but no adequate current result.
- `To remove`: the wording is unsupported, misleading, or outside the selected study and must not remain as a paper claim.

Passing a unit test supports only the tested implementation behavior. It does not establish a cryptographic theorem, distributed-system property, usability result, or production readiness.
