# LOCUS Anonymous Package Guide

This directory contains reviewer instructions for
`LOCUS-anonymous-artifact-v2`. The package includes the frozen Yi TPASS
baseline implementation, Python orchestration, synthetic fixtures, isolated
same-host deployment, retained aggregate v2 evidence, deterministic processing,
and generated performance-table inputs.

Read these files in order:

1. `INSTALL.md` for pinned prerequisites and setup.
2. `EVALUATION.md` for commands and expected observations.
3. `MANIFEST.md` for the inclusion, provenance, licensing, and privacy boundary.

Project-authored software and configuration are licensed under Apache License
2.0. Project-authored documentation and aggregate experiment material are
licensed under CC BY 4.0 with `LOCUS Authors` as the designated attribution.

LOCUS is a research prototype. It is not production-ready, independently
audited, or suitable for real keys or personal recovery data. This package is a
reproducibility boundary for the frozen baseline; it does not claim evidence for
later recovery suites or architecture profiles.
