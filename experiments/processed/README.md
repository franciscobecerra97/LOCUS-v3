# Processed Performance Result

`performance-v1/` is immutable superseded history. The description below
applies to the retained v2 baseline. A changed implementation profile must use
a new processed-result version and must not consume a mixed corpus.

`performance-v2/summary.json` is the deterministic result derived from the
exact 30 retained performance records:

```text
experiments/raw/performance-v2/{01..10}/<scenario>.json
```

Verify it without overwriting the checked-in result:

```console
uv run --frozen python tasks.py process-performance --verify
```

The processor validates every input path, digest, experiment identifier,
source revision, pseudonymous host, lockfile, runtime, seed-derived scenario
order, and trace policy. It then recomputes the source series, descriptive
statistics, and deterministic bootstrap intervals.

The canonical SHA-256 digest of the packaged processed result is:

```text
462e492795fafdd90a4f39851a612275193603d816f761728afe05e97a470a6b
```

The checked-in summary has been regenerated byte-for-byte from the retained
inputs. Existing processed output is never overwritten by verification mode.
